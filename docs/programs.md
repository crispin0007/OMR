# Programs and categories

[Guide home](index.md) · Previous: [Create an exam](create-an-exam.md) · Next: [Templates](templates.md)

An institute often prepares students for several courses at once: IOE, Medical (CEE), CMAT, or JEE
and NEET. **Programs** keep each course's exams and test series together, and **categories** split
a program further, for example *Chapter tests* and *Full mocks*.

## Make a program

1. Open **Exams** in the sidebar.
2. Under **Programs** on the left, press **New program…**, type its name (for example `IOE`), and
   pick a colour if you like. **Institute** sets the letterhead its exams print, if it isn't the
   default one.
3. With the program chosen, press **New category…** to add categories inside it.

**Change…** renames a program or category, or changes its colour or institute. **Delete…** removes
it, but never its exams: a category's exams move to its program, and a program's exams move to
*No program*.

## Put exams in them

- Choose a program or category on the left, then press **New exam…**: the new exam goes there.
- To move an exam, open it, go to **Exam settings** and pick its **Program**.

## Find an exam

Choose a program or category to list only its exams (a program shows its categories' exams too).
The line above the list sums it up: how many exams, test series and sheets read. **Search exams**
finds an exam by name. **All exams** shows everything again.

An exam prints the institute it picks on **Exam settings**; if it doesn't pick one, its category's,
then its program's, then the default institute.
