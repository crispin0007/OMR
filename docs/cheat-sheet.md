# OMR Checker cheat sheet

*Print this page and keep it next to the scanner.* Full guide: [docs/index.md](index.md)

## The 5 steps

| Step | Where | What to press |
|---|---|---|
| 1. Create the exam | Exams | **New exam…** (Ctrl+N) → Next … → **Create exam** |
| 2. Print the sheets | Exam > Print sheet | **Check a printed copy…** on one, then **Print…** or **Save as PDF…** |
| 3. Answer key | Exam > Answer key | Type the letters: A C B D… |
| 4. Scan | Exam > Scan | Sheets in the feeder → **▶ Start scanning** |
| 5. Results | Exam > Review, then Results | Fix each item → **Merit list (Excel)…**, **Scorecards (PDF)…** or **Results (CSV)…** |

## Keys

| Key | Where | Does |
|---|---|---|
| Ctrl+N | Anywhere | New exam |
| Ctrl+O | Anywhere | Import scans into the open exam |
| F1 | Anywhere | Help |
| A, B, C… | Answer key | Set the answer and go to the next question |
| Shift+letter | Answer key | Add a second answer the student must also fill |
| `*` | Answer key | Bonus question (everyone gets the marks) |
| Space | Answer key | Drop the question (counts for no one) |
| `/` | Answer key | Either of the ticked answers is right |
| A, B, C… | Review | Pick that answer |
| Delete | Review | Blank |
| X | Review | Invalid: two marks, even a faint one |
| Space | Review | Keep as read |

## Colours on the live sheet

**Green** right · **Red** wrong · **Blue** read, no key yet · **Orange box** check later in Review

## Before scanning

- Scanner on, **✓ Scanner ready** shown on the Scan tab
- Resolution **200 DPI**
- **Both sides** ticked only if the scanner scans both sides
- Sheets flat, all the same way up, corners not folded

## If something goes wrong

| Problem | Do this |
|---|---|
| No scanner found | Switch on → **Find scanners**; or scan to a folder and pick **A folder my scanner software saves into**; or **Import scans…** |
| Paper jam | Clear it, put the rest back, **Start scanning** again; nothing read is lost |
| Page couldn't be read | Check the four corner circles; scan it again |
| Sheet scanned twice | Scanned sheets → select one → **Delete…** |
| Wrong exam | Scanned sheets → select → **Move to exam…** |

## After every exam

Exams → **Back up…** → save to a USB drive.
